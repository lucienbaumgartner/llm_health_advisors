Empathy in Real vs. Synthetic Clinician Comments

1 Summary

Across 3 synthetic models (Gemini, Grok, Openai) and 3 prompting methods (DG, SAG, SAGII), real comments generally show significantly higher empathy ratings across all 3 mechanisms (Emotional Reactions, Interpretations, Explorations), with one exception: for Interpretations, Grok scores significantly higher than real across all 3 prompting strategies (DG, SAG, SAGII).

2 Data

6600 Reddit posts were used, each paired with its real clinician comment(s) and synthetic comments from 3 models x 3 prompting methods. 137278 comments were classified in total: 8625 real and 128653 synthetic (14295 per model/method group on average). Predicted empathy comes from the same three fine-tuned RoBERTa bi-encoder classifiers used in pilot 1 (Emotional Reactions, Interpretations, Explorations; see ../2_training), each producing an ordinal label: 0 = none, 1 = weak, 2 = strong.

5 Mixed-effects models

The Mann-Whitney tests above treat every comment as independent, but they aren’t: several synthetic comments (and sometimes several real ones) come from the same Reddit thread, so they share whatever makes that particular topic more or less emotionally charged or explorable. To account for that, we run two mixed-effects models per mechanism:

  • A - omnibus (label ~ group + log(length) + (1|post_id), all 137278 comments): tests whether the 10-level group factor (real + 9 model/method combinations) matters at all.
  • B - model × method (label ~ model * method + log(length) + (1|post_id), synthetic comments only - “real” has no model/method to cross): tests the model main effect, the method main effect, and whether they interact.

Emotional Reactions uses all 3 empathy levels, so it’s fit as a cumulative link mixed model (ordinal::clmm). Interpretations and Explorations never predict label 1 anywhere in this data (0 occurrences out of 137278 comments, checked directly), so a 3-level ordinal model would be degenerate for them—they’re fit instead as binomial mixed models (lme4::glmer) on P(label = 2).

The model x method interaction is significant for all 2 mechanisms it could be tested for—not estimable for Emotional Reactions, whose Model B fit failed to converge, i.e. for those mechanisms the effect of a prompting method genuinely depends on which model generated it. Both main effects (model and method) are significant for every mechanism they could be tested for, on top of the interaction. Emotional Reactions’s model and method main effects aren’t estimable here—its Model B fit failed to converge, so there’s no valid test for any term in it beyond what’s noted above.

Since the interaction is significant for at least one mechanism, pooled main-effect means (averaged over the other factor) would be misleading there - e.g. a model’s “average” effect can look muted if it does well with one method and poorly with another. So instead, two sets of simple-effects contrasts throughout: models compared within each method, and methods compared within each model. Emotional Reactions is omitted from both tables below—its Model B fit failed to converge, so there are no valid contrasts to report.
